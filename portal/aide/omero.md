## Serveur OMERO

![OMERO](/images/omero-logo-200.png)

OMERO permet de stocker toutes vos images à un seul endroit et ce, de façon sécuritaire. Vous pouvez sauvegarder, voir, organiser, analyser et partager vos images partout où vous avez accès à Internet. OMERO vous permet de pouvoir travailler avec vos images en utilisant une application installable sur votre ordinateur (Windows, Mac et Linux), à partir d'un fureteur Internet ou via certaines applications tierces. Plus de 140 formats d'images sont supportés, incluant la majorité des formats utilisés en microscopie.

[Site officiel (en anglais)](http://www.openmicroscopy.org/site/products/omero)

Vous pouvez utiliser [OMERO.web](http://omero.ccs.usherbrooke.ca/) ou le client [OMERO.insight](http://downloads.openmicroscopy.org/latest/omero5) afin de voir, organiser et partager vos données. Si vous avez besoin d'aide avec le serveur OMERO ou si vous désirer avoir votre compte sur le serveur OMERO, contactez [Daniel Garneau](mailto:Daniel.Garneau@USherbrooke.ca).


### Aide pour le serveur OMERO :

1. **Installation du client OMERO.insight (Windows, Mac, Linux)**
    * Télécharger le client OMERO [ici](http://downloads.openmicroscopy.org/omero/5.1.0/).
    * L'adresse du serveur est "omero.ccs.usherbrooke.ca" (vous en aurez besoin lors des prochaines étapes).
    * Suivre les instruction se trouvant [ici](http://help.openmicroscopy.org/getting-started-5.html).
<br>
<br>
2. **Changer votre mot de passe avec [OMERO.web](http://omero.ccs.usherbrooke.ca/)**
    * Cliquer sur votre nom apparaissant en haut à droite de l'écran.
    * Sélectionner "User Settings".
    * Cliquer sur le bouton "Change Password" dans le bas de la page.  
    ![Changer de mot de passe](/images/omero_change_password.png)
<br>
<br>
3. **Télécharger des images se trouvant sur le serveur avec OMERO.web et le client OMERO.insight**
    * Sélectionner une ou des images.
    * Cliquer sur la flèche se trouvant en haut du panneau de droite.
    * Sélectionner "Download..." pour télécharger le format original ou choisisser le format désiré.
<br>
<br>
4. **Téléverser des images sur le serveur OMERO**  
*Vous devez utiliser le client OMERO.insight pour téléverser des images sur le serveur OMERO*
    * Dans OMERO.insight, ouvrir "Importer" en cliquant sur la flèche bleue avec trois points.  
    ![Ouvrir "Importer"](/images/omero_insight_open.png)
    * Dans la fenêtre "Import Data" :
        * Dans le panneau de gauche, naviguer à l'endroit où se trouvent vos images.
        * Sélectionner les images ou les dossiers contenant les images que vous voulez importer sur le serveur.
        * Cliquer sur la flèche se trouvant entre les deux panneaux afin de confirmer la sélection.
        * Sélectionner ou créer un "Projet" (les projets correspondent aux dossiers principaux).
        * Sélectionner ou créer un "Dataset" (les datasets correspondent aux sous-dossiers).
        * Cliquer sur "Add to the Queue".
        * Vous pouvez visualiser un résumé des images qui seront envoyées et dans quelles projet/dataset elles seront mises.
        * Cliquer sur "Import" afin d'envoyer vos images sur le serveur.
    * Une fois le téléversement terminé, assurez-vous de cliquer sur "Refresh the tree" si vous voulez voir vos images.
    * Plus d'informations [ici](http://help.openmicroscopy.org/importing-data-5.html).
<br>
<br>
5. **Voir les images d'autres utilisateurs**
    * À noter que vous pouvez uniquement voir les images des personnes étant dans le même groupe (laboratoire) que vous.
    * **Avec OMERO.web**
        * Cliquer à l'endroit où on voit le nom de l'utilisateur en haut du panneau de gauche.
        * Sélectionner le groupe et l'utilisateur désiré.  
        ![utilisateurs](/images/omero_view_other_users.png)
    * **Avec le client OMERO.insight**
        * Cliquer sur "Display Groups" en haut de la fenêtre.
        * Sélectionner le groupe et l'utilisateur désiré (plusieurs groupes et utilisateurs peuvent être sélectionnés simultanément)  
        ![utilisateurs](/images/omero_view_other_users_insight.png)
<br>
